# TechHelp

O TechHelp é um projeto desenvolvido para conectar clientes a profissionais de TI.

A plataforma permite que clientes publiquem solicitações de serviços e que técnicos enviem propostas para realizar esses atendimentos.

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MariaDB

### Frontend
- React
- TypeScript
- Vite

### Banco de dados
- MariaDB

## Estrutura

- `backend/` - API do sistema
- `database/` - script do banco de dados
- `frontend/` - interface web do projeto
